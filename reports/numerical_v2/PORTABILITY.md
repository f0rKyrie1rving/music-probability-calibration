# Numerical portability v2

**Passed on macOS, Linux and Windows.** The [complete verification run](https://github.com/f0rKyrie1rving/music-probability-calibration/actions/runs/36978254282)
tested candidate `816dec19044ce45d0496c4f720d33cc419309a52`. Each system completed
166 tests and all six frozen plans: 2,160 case executions, covering 1,560 distinct
source/subset conditions. All three systems selected identical ridge penalties
and made identical final and inner-fold fallback decisions, including unselected
candidates. There are no diagnostic exceptions.

The correction replaces platform-sensitive optimizer termination with bounded
Newton steps and explicit convergence checks. The statistical methods, objective
functions, parameter bounds, input scores and six sampling plans remain unchanged.
Independent verification reconstructs objectives, gradients, constrained
first-order conditions, every saved prediction, OOF selection and reported metric.
An interrupted run cannot resume on another operating system or architecture.

## Full numerical comparison

Each comparison checked 60,480 method/label fit records, 14,563,584 evaluation
probabilities, 7,250,400 candidate OOF probabilities, 51,840 OOF scores, and all
42 numerical report files. The tolerance remains absolute `1e-8`, relative `0`;
selections and all fallback flags, reasons and counts must match exactly.

| Comparison | Largest evaluation-probability difference | Largest OOF-probability difference | Result |
|---|---:|---:|---|
| Linux vs CI macOS | 1.16074e-13 | 1.83575e-13 | Passed |
| Windows vs CI macOS | 1.16074e-13 | 1.83575e-13 | Passed |
| Local macOS vs CI macOS | 0 | 0 | Passed |

The largest OOF-score difference across systems was `1.04639e-14`. On **each**
system, all 159,327 optimizer fits converged. There were zero numerical-failure
fallbacks; 360 single-class inner fits retained their declared identity fallback.
The 600 repeated full-budget executions matched exactly within each environment.
The repeat controls are not counted as new independent scientific observations.

The tested runtime was Python 3.13.15, NumPy 2.5.2, SciPy 1.18.1 and scikit-learn
1.9.0, with the remaining dependencies pinned in `requirements-lock.txt`.
Full OS/architecture and loaded numerical-library records are preserved below.
This result establishes agreement on these environments and inputs; it is not
a universal bitwise-reproducibility guarantee for every future computer or input.

probability-level comparison requires the generated signatures or CI artifacts.

## Interpretation

This is an engineering reproducibility correction on previously observed data.
It does not establish better genre accuracy or fresh-data calibration performance.
More complete optimization changes three v1 label choices and can worsen some
predictions; the [paired v1-to-v2 diagnostic](LEGACY_DIFFERENCES.md) retains both
favorable and unfavorable changes, including a small increase in mean Ridge
Brier. All original v1 code, protocols and results remain unchanged.
